# Когда настройку можно считать законченной

Проверки выполняет Claude после настройки. Этот файл сам по себе не означает, что они пройдены.

| Проверка | Критерий |
|---|---|
| Настройки сохранены | Сделана локальная резервная копия изменяемых файлов; hooks, MCP и существующие правила сохранены; нет перезаписи всего settings.json шаблоном |
| Модели | Новая сессия запущена обычным `claude` без `--settings`/`--model`/`--effort`, чтобы временные параметры не скрыли ошибки сохранения; подтверждены выбранная Fable/Opus, effort и доступ аккаунта; настройки используемых субагентов сверены |
| Память | `/memory` показывает установленный глобальный CLAUDE.md; контекст нужного проекта находится и читается |
| Реестр | Найдены существующие рабочие каталоги; не созданы дубликаты; недоступные/удалённые проекты явно отмечены |
| Незавершённая работа | Git status важных проектов сохранён до/после; чужие изменения не затронуты |
| Навыки | Личные контент-навыки видны Claude; относительные ссылки работают; адаптация не ссылается на несуществующие инструменты Codex |
| GitHub | Подтверждён нужный аккаунт и чтение нужного репозитория; push/PR для проверки не выполнялись |
| VPS | Проверен целевой SSH alias; при наличии доступа пройдена безвредная read-only команда; на старый сервер записи нет |
| MCP | Для нужных интеграций установлен реальный клиент/сервер и выполнено чтение; наличие записи в JSON не считается авторизацией |
| Браузер | Открыта публичная страница, выполнены screenshot и безвредная навигация; доступ к личному профилю отдельно подтверждён, если нужен |
| Документы | Создан и открыт небольшой локальный пример нужного формата; проверено отображение, если поддержка заявлена |
| Проект | Claude в существующем проекте нашёл правильный статус, назвал следующий шаг и выполнил подходящую безопасную проверку без выпуска в продакшен |
| Завершение | Есть setup-report.md: настроено / проверено / требует входа / недоступно; указаны реальные версии, пути, модели и дата |

Используй самые дешёвые по последствиям проверки: локальные временные файлы, публичную тестовую страницу, read-only API. Настройка не требует рассылок, платежей, создания реальных лидов, платной генерации медиа, push в main и проверки через изменение продакшен-данных. Не запускай полный набор тестов каждого проекта ради инвентаризации.
