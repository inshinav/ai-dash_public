1. **Войти в свой Claude-аккаунт.** Claude Code уже установлен, но сейчас не авторизован. Подготовь вход/2FA и доступ к Fable/Opus. Тариф и доступные лимиты проверяются после входа. Fable на части планов требует отдельных usage credits; не покупай их заранее на основании одного этого пакета. [Доступ моделей](https://code.claude.com/docs/en/model-config#fable-and-usage-credits).
2. **Оставить доступными существующие папки на этом компьютере.** Копировать проекты заново не нужно. GitHub уже авторизован; SSH alias настроен. Успешное подключение к VPS пока не проверялось.
3. **Быть готовым подтвердить отдельные входы Google/Figma/Cloudflare**, если Claude запросит их по делу. Пароли, токены и приватные ключи присылать в чат не нужно.
4. **Перед редактированием продукта завершить параллельную работу над теми же файлами.** В Lola Flow обнаружены незакоммиченные изменения. Сама настройка Claude не должна их затронуть.

Пакет не переносит содержимое облачных ChatGPT-проектов и полную историю разговоров. Он передаёт рабочие инструкции, известные пути и точки продолжения. Индекс чатов — навигация, а не импорт Claude-сессий.

```powershell

```

Скрипт обновит установленный Claude его собственным updater, проверит версию и откроет интерактивную Fable 5.1 с ultracode, передав ей BOOTSTRAP.md. Сессионный профиль ограничивает модели уже с первого запуска настройки. Пройди вход, если Claude предложит. Скрипт не был запущен при подготовке пакета: обновление, вход и настройка будут происходить при твоём запуске.

Если Fable недоступна или просит дополнительные credits, можно начать на разрешённой Opus:

```powershell

```

Выбор Opus сохранится основной моделью после настройки; Claude не должен автоматически возвращать тебя на Fable.

Если Windows блокирует запуск .ps1, не меняй системную execution policy. Выполни вручную:

## Выбранный профиль

Основная модель — **Fable 5.1**, альтернатива — **Opus 5.5**, режим — **ultracode**. Это актуальные проверенные версии на дату пакета. [Fable](https://platform.claude.com/docs/en/models/fable-5-1/overview), [Opus](https://platform.claude.com/docs/en/models/opus-5-5/overview).

Ultracode означает xhigh и автоматическое распределение работы между агентами. Самый глубокий отдельный reasoning — max; эти режимы не следует выдавать за одно и то же. [Документация workflows](https://code.claude.com/docs/en/workflows).

Рабочий выбор ограничивается Fable/Opus, включая вспомогательных исполнителей. Проверка фактических моделей входит в настройку. `CLAUDE.md` задаёт поведение, а возможности определяются также клиентом, инструментами, аккаунтом и разрешениями; одинаковое качество любой задачи с Codex гарантировать нельзя.
